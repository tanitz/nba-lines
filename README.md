# ตามราคา NBA (NBA Line Tracker)

เว็บแอปที่ดึงราคา **แฮนดิแคป (spread)** และ **สูง/ต่ำ (totals)** ของ NBA จาก [The Odds API](https://the-odds-api.com) อัตโนมัติ
เก็บประวัติทุกครั้งที่ราคาเปลี่ยนจนถึงเวลาเริ่มแข่ง แล้วแสดงเป็นกราฟ

- ดึงราคาเองตามเวลา ยิ่งใกล้แข่งยิ่งถี่ (3 ชม. → 1 ชม. → 20 นาที → 10 นาที) เพื่อประหยัดเครดิต
- หยุดเก็บเมื่อแมตช์เริ่ม เก็บเฉพาะราคาก่อนแข่ง
- หน้าเว็บเป็นภาษาอังกฤษ แสดงเป็นตาราง 1 แถวต่อ 1 แมตช์ (ราคาเปิด / ล่าสุด / การขยับ / ค่าน้ำ) กดแถวเพื่อดูกราฟ ตารางเทียบทุกเจ้ามือ และประวัติราคาทุกครั้งที่เปลี่ยน
- เลือกดูแยกตามเจ้ามือ หรือ "Market consensus" (มัธยฐานทุกเจ้า)
- แสดงค่าน้ำได้ 4 แบบ: ฮ่องกง มาเลย์ ยุโรป (Decimal) และอเมริกัน
- หลังจบเกม ดึงผลมาเทียบกับราคาปิด (ชนะราคา / ออกสูง-ต่ำ)
- แท็บ Final เลือกวันแข่งย้อนหลังได้ (วันตามเวลาอีสต์ของสหรัฐฯ) ดูกราฟการไหลของราคา แต้มจริง และผลชนะ/แพ้ราคา
- แท็บ Teams และชื่อทีมทุกที่กดได้ เปิดหน้าทีม: แข่งไปกี่นัด เจอใคร เหย้า/เยือน ชนะ-แพ้ ชนะราคา สูงต่ำ แยกตอนเป็นเต็ง/รอง ราคาเปิด-ปิดแต่ละนัด และนัดถัดไป
- หน้าแต่ละเกมมีสถิติแต่ละทีม ชนะราคาแฮนดิแคป (ATS) และออกสูง/ต่ำ (O/U) ในรอบ 10 นัด / 20 นัด / ทั้งซีซั่น และแยกเหย้า/เยือน
  นับเฉพาะนัดที่ระบบเก็บราคาไว้ได้ (เริ่มเก็บ 21 ต.ค. 2026) แผนฟรีของ The Odds API ไม่มีราคาย้อนหลังก่อนหน้านั้น
- ไม่ต้องติดตั้งแพ็กเกจเพิ่ม ใช้ Node.js อย่างเดียว (ฐานข้อมูล SQLite ในตัว)

## วิธีที่ 1: ออนไลน์ฟรีด้วย GitHub (ไม่ต้องเปิดเครื่องทิ้งไว้)

GitHub Actions จะรันสคริปต์ทุก 5 นาที ดึงราคาเมื่อถึงรอบ เก็บฐานข้อมูลไว้ใน branch `data`
แล้วอัปเดตหน้าเว็บบน GitHub Pages ให้เอง ได้ลิงก์แบบ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`

1. สร้าง repo ใหม่ที่ github.com/new ตั้งเป็น **Public** (ใช้ Actions และ Pages ได้ฟรีไม่จำกัด)
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้น branch `main` ให้มีไฟล์ `.github/workflows/update.yml` ด้วย
3. **Settings → Secrets and variables → Actions → New repository secret**
   ชื่อ `ODDS_API_KEY` ค่า = คีย์ของคุณ (คีย์ถูกเก็บเป็นความลับ คนอื่นไม่เห็น)
4. **Settings → Pages → Build and deployment → Source** เลือก **GitHub Actions**
5. แท็บ **Actions → เก็บราคา NBA → Run workflow** เพื่อรันครั้งแรก
6. รอราว 1 นาที แล้วเปิดลิงก์ที่ขึ้นใน Settings → Pages

ข้อควรรู้
- ค่าเริ่มต้นใน workflow ตั้งให้พอดีแผนฟรี 500 เครดิต/เดือน (ดึงราคาราว 7 ครั้งต่อวัน เน้นช่วงใกล้แข่ง)
  ถ้าอัปเกรดแผน ให้ไปที่ **Settings → Secrets and variables → Actions → Variables** แล้วตั้ง
  `POLL_FAR_MIN=180`, `POLL_DAY_MIN=60`, `POLL_NEAR_MIN=20`, `POLL_CLOSE_MIN=10`, `SCORES_EVERY_HOURS=4`
- ตัวตั้งเวลาของ GitHub อาจช้ากว่ากำหนด 5–15 นาที หรือข้ามไปเป็นช่วง ๆ (เคยหายไปราว 50 นาที) จึงตั้งให้ปลุกทุก 5 นาที
  และถ้ารอบดึงราคาตกค้างเพราะถูกข้าม สคริปต์จะดึงชดเชยทันทีที่มีรอบถัดไป
- repo เป็น Public ราคาที่เก็บจึงเปิดดูได้ แต่คีย์ API ไม่หลุด
- ถ้า GitHub หยุด workflow อัตโนมัติ (เกิดได้เมื่อ repo ไม่มีความเคลื่อนไหว 60 วัน) ให้เข้าแท็บ Actions แล้วกด Enable
- ดาวน์โหลดฐานข้อมูลได้จาก branch `data` (ไฟล์ `odds.db`)

## วิธีที่ 2: รันเป็นเซิร์ฟเวอร์ (VPS หรือเครื่องตัวเอง)

ได้หน้าเว็บที่อัปเดตทันที และกดดึงราคาเองได้ เหมาะถ้ามี VPS อยู่แล้ว

ต้องมี **Node.js 22.13 ขึ้นไป**

```bash
cp .env.example .env        # แล้วใส่ ODDS_API_KEY
npm start                   # เปิด http://localhost:3000
```

สมัครคีย์ได้ที่ https://the-odds-api.com (มีแผนฟรี)

อยากลองหน้าตาก่อนโดยไม่ใช้คีย์:

```bash
npm run demo                # ข้อมูลตัวอย่างแบบสุ่ม ไม่ใช่ราคาจริง
```

## เครดิต API และความถี่การดึง

คำขอ `/odds` หนึ่งครั้งได้ราคาของทุกแมตช์ที่ยังไม่เริ่ม ค่าเครดิต = จำนวนตลาด (2) × จำนวนภูมิภาค
ตั้ง `REGIONS=eu` ภูมิภาคเดียว จึงเสียครั้งละ **2 เครดิต** ส่วนผลการแข่งขันเสียครั้งละ 2 เครดิต (ตารางด้านล่างคือค่าเริ่มต้นของวิธีที่ 2)

| ระยะก่อนแมตช์ที่ใกล้ที่สุด | ตัวแปร | ค่าเริ่มต้น |
|---|---|---|
| มากกว่า 24 ชม. | `POLL_FAR_MIN` | 180 นาที |
| 6–24 ชม. | `POLL_DAY_MIN` | 60 นาที |
| 1–6 ชม. | `POLL_NEAR_MIN` | 20 นาที |
| น้อยกว่า 1 ชม. | `POLL_CLOSE_MIN` | 10 นาที |
| ไม่มีแมตช์ (ปิดฤดูกาล) | `POLL_IDLE_MIN` | 360 นาที |

- ค่าเริ่มต้นของเซิร์ฟเวอร์ใช้ราว 4,000 เครดิตต่อเดือนช่วงฤดูกาล เหมาะกับแผน 20K
- แผนฟรี (500 เครดิต/เดือน) ให้ตั้งตามค่าที่เขียนไว้ใน `.env.example` จะได้ราววันละ 7 ครั้ง
- เมื่อเครดิตเหลือต่ำกว่า `MIN_CREDITS_LEFT` ระบบจะชะลอเหลือวันละไม่กี่ครั้งเอง
- หน้าเว็บแสดงเครดิตคงเหลือ เวลาดึงล่าสุด และรอบถัดไป

## นำขึ้นเซิร์ฟเวอร์

ต้องรันตลอด 24 ชม. ถึงจะเก็บราคาได้ต่อเนื่อง บริการฟรีที่ "หลับ" เมื่อไม่มีคนเข้า จะทำให้ข้อมูลขาดช่วง

**เครื่องตัวเองหรือ VPS (แนะนำ pm2)**

```bash
npm i -g pm2
pm2 start "npm start" --name nba-lines
pm2 save && pm2 startup
```

**Docker**

```bash
docker build -t nba-lines .
docker run -d --name nba-lines -p 3000:3000 \
  -v nba-data:/data --env-file .env --restart unless-stopped nba-lines
```

**Railway / Fly.io / Render (แบบเสียเงิน)** ใช้ Dockerfile นี้ได้เลย ต้องผูก volume ไว้ที่ `/data`
เพื่อไม่ให้ฐานข้อมูลหายเมื่อ deploy ใหม่

**ใช้ cron ของระบบแทนตัวตั้งเวลาในแอป** ก็ได้: `node src/poller.js --once` จะดึงราคาหนึ่งครั้งแล้วจบ

## อ่านตัวเลขบนหน้าเว็บ (ภาษาอังกฤษ)

หน้าแรกเป็นตาราง 1 แถวต่อ 1 แมตช์ กดที่แถวเพื่อเข้าไปดูรายละเอียด แท็บ **Upcoming** คือแมตช์ที่ยังไม่เริ่ม
แท็บ **Final** คือแมตช์ที่แข่งแล้วใน 10 วันล่าสุด

| คอลัมน์ | ความหมาย |
|---|---|
| Game | ทีมเยือน @ ทีมเหย้า พร้อมเวลาเตะตามเขตเวลาของเครื่องคุณ |
| Spread: Open / Now (Close) / Move | แต้มต่อตอนเปิด ล่าสุด (หลังเริ่มแข่งเรียก Close) และการขยับ เช่น `BOS -5.5` คือ Boston ต่อ 5.5 แต้ม ส่วน `→ NYK 0.5` คือราคาขยับไปทาง NYK 0.5 แต้ม |
| Home odds / Away odds | ค่าน้ำล่าสุดของทีมเหย้า / ทีมเยือนที่แต้มต่อนั้น |
| Total points: Open / Now (Close) / Move | เส้นสูง/ต่ำ ตอนเปิด ล่าสุด และการเปลี่ยน (`+2` = เส้นขึ้น 2 แต้ม) |
| Over odds / Under odds | ค่าน้ำฝั่งสูง / ต่ำ |
| Result (เฉพาะ Final) | สกอร์จริง, ATS = ทีมที่ชนะแต้มต่อปิด, O/U = ออกสูงหรือต่ำเทียบเส้นปิด |

หน้ารายละเอียดแมตช์เรียงเป็นบล็อก: **Movement summary** (เส้นต่อ เส้นสูง/ต่ำ และค่าน้ำทั้งสองฝั่ง: Open / Now / Change / Min / Max / Updates)
→ **Charts** (กราฟเส้นต่อ กราฟค่าน้ำ กราฟเส้นสูง/ต่ำ กราฟค่าน้ำสูง/ต่ำ พร้อมเส้นประบอกเวลาเริ่มแข่ง)
→ **Current line by bookmaker** (ราคาล่าสุดของทุกเจ้า และสีบอกว่าเจ้าไหนขยับจากราคาแรกที่เจ้านั้นเปิด)
→ **Price history** (ทุกครั้งที่เส้นหรือค่าน้ำเปลี่ยน ใหม่สุดอยู่บน)

**สีบอกการเปลี่ยนแปลง** (ใช้ทั้งเส้นราคาและค่าน้ำ)
- เขียว ▲ = ค่าขึ้น, แดง ▼ = ค่าลง, ไม่มีสี = ไม่เปลี่ยน มีลูกศรกำกับเสมอ ไม่ได้ใช้สีอย่างเดียว
- หน้าแรกเทียบ "ราคาเปิด → ล่าสุด" (ราคาเปิดของค่าน้ำแสดงเป็นตัวเล็กใต้ราคาล่าสุด) ส่วนตารางประวัติเทียบกับแถวก่อนหน้า
- เส้นต่อ: ▲/▼ ตามตัวเลขแต้มต่อของทีมเหย้า (▼ = ราคาไหลไปทางเจ้าบ้าน) และมีข้อความ "toward ทีม" กำกับ
- จุดสีน้ำเงิน = เจ้าบ้าน / Over, จุดสีส้ม = ทีมเยือน / Under ตรงกับสีเส้นในกราฟ

- **แต้มต่อ** เก็บจากมุมทีมเหย้า (ค่าติดลบ = เจ้าบ้านต่อ) แต่หน้าเว็บแสดงจากมุมทีมต่อ เช่น `BOS -5.5` กราฟแต้มต่อจึงวาดค่าของเจ้าบ้าน ต่ำกว่า 0 = เจ้าบ้านต่อ
- **ค่าน้ำ** เก็บเป็นทศนิยมยุโรป แล้วแปลงตอนแสดง: ฮ่องกง = ยุโรป − 1, มาเลย์ = ฮ่องกง ถ้าน้อยกว่า 1 หรือ −1/ฮ่องกง ถ้ามากกว่า 1, อเมริกัน = +100×(ยุโรป−1) หรือ −100/(ยุโรป−1)
  กราฟค่าน้ำแบบมาเลย์และอเมริกันวาดเป็นฮ่องกง/ยุโรปแทน เพราะตัวเลขกระโดดข้าม ±1 / ±100
- **Market consensus** = มัธยฐานของทุกเจ้ามือ ณ เวลานั้น
- **ATS ชนะราคา** = ผลต่างคะแนนจริงบวกแต้มต่อปิด มากกว่า 0

## API ของแอป

| เส้นทาง | คืนค่า |
|---|---|
| `GET /api/status` | เวลาดึงล่าสุด รอบถัดไป เครดิตคงเหลือ รายชื่อเจ้ามือ |
| `GET /api/games?scope=upcoming\|recent&book=consensus\|<key>` | รายการแมตช์พร้อมราคาเปิด/ล่าสุด |
| `GET /api/games/:id?book=...` | ประวัติราคาทั้งหมดของแมตช์ |
| `POST /api/poll` (header `x-admin-token`) | สั่งดึงราคาทันที (ต้องตั้ง `ADMIN_TOKEN`) |

```
src/config.js      อ่าน .env
src/oddsApi.js     เรียก The Odds API และแปลงข้อมูล

src/db.js          ตาราง SQLite (games, snapshots, bookmakers, polls)
src/series.js      สร้างเส้นกราฟ ค่ากลางตลาด และสรุปการขยับ
src/server.js      เว็บเซิร์ฟเวอร์ + API
src/demo.js        ข้อมูลตัวอย่างแบบสุ่ม
public/            หน้าเว็บ (Chart.js)
scripts/ci-run.js          รอบเดียวสำหรับ GitHub Actions (ดึงราคา + สร้างเว็บ)
scripts/build-site.js      สร้างเว็บไฟล์นิ่งลงโฟลเดอร์ site/
scripts/export-static.js   สร้างหน้าเว็บไฟล์เดียวจากฐานข้อมูล
.github/workflows/update.yml  ตัวตั้งเวลาบน GitHub
test/              npm test
```
